Project name: AgentBreak: A Web-Based Call Center Queue and Break Management System
Steps to run the project:
1. Install Java, Maven, and PostgreSQL.
2. In pgAdmin, create a database named agentbreak.
3. Set the postgres username and password in application properties to the right(your own) details.
4. Run the project as a whole.
5. The API starts on http://localhost:8080(use Postman for the api tests preferably).
6. Import agent-break-call-center-break-management-midterm.postman_collection.json.
